# ⛏️ Ibrahim Amer Minecraft
**© Ibrahim Amer**

لعبة 3D شبيهة بـ Minecraft مكتوبة بلغة Python — عالم من المكعبات والبلوكات،
تعمل على الكمبيوتر (Desktop) وقابلة للتحويل إلى APK للأندرويد.

## ✨ المميزات
- 🌍 عالم 3D من البلوكات (تضاريس + أشجار) يتولد تلقائيًا
- 🕹️ حركة + قفز + تحريك الكاميرا (ماوس على الكمبيوتر / سحب باللمس على الموبايل)
- ⛏️ كسر البلوكات (كليك يسار / زر ⛏) ووضعها (كليك يمين / زر 🧱)
- 🧱 4 أنواع بلوكات: **Grass عشب / Dirt تراب / Stone حجر / Wood خشب** (+ أوراق وزجاج أساس)
- 📱 أزرار تحكم على الشاشة: أسهم الحركة ▲▼◀▶ + قفز + كسر + بناء + شريط اختيار البلوكات
- 🎮 واجهة بسيطة بأسلوب Minecraft + اسم اللعبة والحقوق داخل اللعبة

## 📁 ملفات المشروع
| ملف | الوظيفة |
|---|---|
| `main.py` | اللعبة كاملة (Ursina 3D + أزرار اللمس + HUD) |
| `world_core.py` | منطق العالم (تضاريس/كسر/وضع) بدون نافذة — يُستخدم للاختبار |
| `textures.py` | توليد خامات PNG بأسلوب Minecraft تلقائيًا |
| `assets/` | الخامات المولدة + خط Amiri العربي (مدمج مع اللعبة) |
| `requirements.txt` | المكتبات: ursina + pillow + numpy + arabic-reshaper + python-bidi |
| `buildozer.spec` | إعدادات التحويل إلى APK |
| `run_desktop.sh` | تشغيل سريع على الكمبيوتر |
| `test_world.py` | اختبارات headless لمنطق العالم |

## 🖥️ التشغيل على الكمبيوتر
```bash
cd ibrahim_amer_minecraft
pip install -r requirements.txt
python main.py
```
التحكم:
- `WASD` حركة | `مسافة` قفز | `ماوس` تدوير الكاميرا
- `كليك يسار` كسر | `كليك يمين` بناء | `1-4` اختيار البلوك
- أزرار الشاشة تعمل بالماوس أيضًا (تدريب لاستخدام الموبايل)

## 📱 التحويل إلى APK (Android)
```bash
pip install buildozer
buildozer android debug
# الملف الناتج في: bin/*.apk
# للتثبيت المباشر: buildozer android deploy run
```
- أزرار اللمس (D-Pad + قفز + كسر/بناء) تعمل باللمس لأن اللمس يصل كـ mouse events.
- تدوير الكاميرا: اسحب بإصبعك على أي منطقة فارغة من الشاشة.
- الاتجاه `landscape` مضبوط في `buildozer.spec`.

## ⚠️ ملاحظة تقنية
Ursina مبنية على Panda3D (OpenGL). على الأندرويد تحتاج جهازًا يدعم
OpenGL ES 2+ ومعمارية arm64. إذا واجهت مشكلة في Panda3D على جهاز معين،
فمنطق العالم في `world_core.py` مستقل تمامًا عن المحرك ويمكن إعادة استخدامه
مع renderer آخر (Kivy/Godot) دون تغيير قواعد اللعبة.
